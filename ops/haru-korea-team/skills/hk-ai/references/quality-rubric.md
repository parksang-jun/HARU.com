# 일정 품질 루브릭 (10점)

| 항목 | 배점 | 기준 | 검증 방법 |
|---|---|---|---|
| 장소 실존·영업 중 | 3 | 모든 스톱이 실제·현재 운영 장소. 폐업·가상 장소 1곳당 −1(최소 0) | 공식 사이트·관광공사(visitkorea)·지도 검색 |
| 좌표 정확도 | 2 | 오차 ≤300m 전부 2점, 1곳 초과 1점, 2곳 이상 0점 | 지도에서 좌표 확인 |
| 동선·시간 현실성 | 2 | 같은 날 스톱 간 이동 ≤40분, 시간 순서·소요시간 합리적, 식사 포함 | 지도 경로·대중교통 소요 |
| 운영일·휴무 반영 | 1 | 휴무일(궁궐 화요일 등)에 배정하지 않음, 야간 시설 시간 적절 | 공식 운영시간 |
| 예약 CTA 적절성 | 1 | 유료 명소·투어·숙소에만 Book, 무료 장소에는 없음, 식당에 Reserve | 스키마 규칙 |
| 언어·톤 | 1 | 요청 언어로 자연스럽고 팁이 구체적(줄서기·현금·시간대) | 원어민 수준 검수 |

판정: 9~10 우수, 7~8 합격, ≤6 불합격(원인 태그 필수).

## 원인 태그
`hallucination`(가상/폐업 장소), `geo`(좌표), `routing`(동선·시간), `hours`(휴무·시간), `cta`(예약 버튼 오배치), `lang`(언어 품질), `schema`(필수 필드 누락·형식)

## 샘플 입력 20개(권장)
서울 2일 솔로 음식·카페 / 서울 4일 커플 역사·쇼핑 / 서울·부산 5일 가족 느긋 / 부산 3일 친구 나이트라이프 / 제주 3일 자연·웰니스 / 경주 2일 역사 / 전주 1일 음식 / 강릉 2일 카페·자연 / 서울 3일 K-pop / 인천 1일 … 언어 en·ja·zh-TW 번갈아, 예산 low/mid/high 섞기.

## 리포트 양식
| 샘플 | 입력 | 점수 | 원인 태그 | 수정 제안 |
평균 점수, 불합격률, 태그 분포, 프롬프트 변경 제안 1~2개.
