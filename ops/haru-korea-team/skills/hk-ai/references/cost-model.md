# 추론 비용 모델 (2026-10 기준 단가 — 분기마다 웹 검색으로 갱신)

## 단가 범위(1M 토큰, USD)

- 소형(Haiku급 / Gemini Flash-Lite): 입력 $0.10~0.25, 출력 $0.50~1.50
- 중형(Sonnet급): 입력 ~$3, 출력 ~$15 (현재 값 확인 필요)
- 플래그십: 입력 $10 / 출력 $50 수준 — 이 앱에서는 사용 금지
- 이미지 생성 $0.03~0.15/장, 비디오 720p 초당 ~$0.10 — 비사용

## 호출당 토큰 가정

| 호출 | 입력 | 출력 | 비고 |
|---|---|---|---|
| 일정 생성(4일) | ~1,500(시스템+파라미터+RAG 후보) | ~4,000(JSON) | tool_use 강제 |
| 일정 재생성 | 동일 | 동일 | 캐시 적중 시 0 |
| 챗 1회 | ~800(시스템+트립 요약+최근 대화) | ~250 | 소형 모델 |

## 세션당 비용 예시

- 일정 1회(중형): 1.5K×$3 + 4K×$15 = $0.0045 + $0.06 ≈ $0.065 → 목표 초과. 출력 축약(2.5K) 또는 소형 모델 사용 시 $0.01~0.04
- 챗 5회(소형): 5×(0.8K×$0.25 + 0.25K×$1.25)/1M ≈ $0.0026
- 결론: 일정 생성 출력 토큰이 비용의 90%. 스키마에서 중복 필드 제거·팁 길이 제한·일수별 분할 생성(요청 시)으로 2.5K 이하 목표.

## 수익 대비

사용자당 어필리에이트 기대수익 ≈ $0.016(클릭률 8%×전환 2%×$10) → 일정당 비용 $0.02 이하가 손익 전제. 쿠폰 광고주 매출이 실질 마진을 만든다(`hk-pm` kpi.md).

## 절감 순서

1. 동일 파라미터 일정 캐시(해시 키, 7일) 2. RAG로 후보 장소 주입 → 출력 축약·환각 감소 3. 1~2일 일정은 소형 모델 4. 챗 컨텍스트 트리밍 5. 일일 한도(기본 일정 3회) 조정
