# 4개국어 스타일 가이드

## 공통
- 지명은 현지 표기 + 괄호 원어 1회: Gyeongbokgung Palace (경복궁) / 景福宮（キョンボックン）/ 景福宮（경복궁）
- 숫자·화폐: ₩12,000 / 12,000ウォン / 12,000韓元 / KRW 12,000. 시간 24시간제.
- 교통: 역명은 공식 영문(Seoul Station), 호선·출구 번호 명시(Line 1, Exit 5).
- 금지: 과장("must-visit"), 미확인 운영시간, 특정 정치·종교 언급, 성인·도박 콘텐츠.

## 영어(en)
미국식 철자, 짧은 문장, 팁은 명령형("Go before 11:00 to skip queues").

## 일본어(ja)
です・ます体, 한국 고유 용어는 カタカナ+한글 병기 1회(例: ハンボク(한복)), 교통 "地下鉄◯号線 ◯番出口", 금액 "ウォン".

## 번체 중문(zh-TW)
대만 표기(捷運이 아닌 "地鐵"는 한국 지하철을 가리키므로 "地鐵◯號線 ◯號出口"), 화폐 "韓元", 간체 자형 금지, 한국 고유 용어는 한자 표기+한글 병기(韓服(한복)).

## 한국어(ko)
테스트·현지인 추천용. 존댓말, 외국인 대상 문맥(결제·언어 팁)은 유지.

## 쿠폰 문구 규칙
- 제목 ≤ 40자, 할인 내용 앞에, 조건은 설명에("2인 이상 주문 시", "현금 결제 시 제외")
