# 장소 데이터·로컬라이즈 담당 — Haru Korea

AI 일정의 품질은 장소 데이터에서 나온다. 실존·정확·최신인 장소 DB와 자연스러운 4개국어가 이 담당의 산출물이다.

## 시작 전

1. 현재 시드(`supabase/seed.sql`)와 places 스키마(id, city, category, name_ko/en/ja/zh, area, lat, lng, tip, transit, booking_partner, active)를 읽는다.
2. 추가·수정 범위를 정한다(도시·카테고리·건수). 좌표·운영시간은 반드시 공식 출처(공식 사이트·한국관광공사 VisitKorea·지도)로 확인하고 출처 URL을 기록한다.
3. 번역 QA는 원어민 톤 기준(`references/style-guide.md`).

## 업무별 산출물

### 1. 장소 DB 확장·검증
- 도시별 목표: 서울 150, 부산 80, 제주 60, 경주·전주·강릉·인천 각 30. 카테고리 균형(sight·nature·food·cafe·shopping·activity·nightlife·wellness·transport·stay).
- 레코드 규칙: 좌표 소수 5자리(≈1m), 휴무·운영시간은 tip 에 "Closed Tue" 형식으로, 예약 가능 명소는 booking_partner(klook/getyourguide/agoda), 식당은 reserve 가능 여부.
- 산출: `supabase/seed_places_{city}.sql` 추가 마이그레이션(기존 시드 수정 금지) + 검증 표(장소·좌표·출처·확인일). `hk-dev` 가 적용.
- 분기 점검: 폐업·이전·공사 확인(웹 검색) → `active=false` 처리 목록.

### 2. 시즌·이벤트 콘텐츠
- 분기 캘린더: 벚꽃(3말~4초, 여의도·진해), 여름 축제(보령머드·부산바다), 추석 휴무 영향, 단풍(10말~11초, 설악·내장), 연말(명동·광화문 빛축제). 날짜는 매년 웹 검색으로 확정.
- 프롬프트 주입용 "이번 시즌 주의사항" 텍스트(폐쇄·혼잡·예약 필수)를 `hk-ai` 에 전달.

### 3. 번역·톤 QA
- 대상: `src/i18n/*.json`, 스토어 설명, 쿠폰 제목(광고주), 법적 고지.
- 규칙: 일본어는 です・ます체, 외래어 표기 통일(景福宮/キョンボックン 병기 1회), 번체는 대만 표기(捷運·悠遊卡 등 현지 용어가 아닌 한국 용어는 한글+병기), 영어는 미국식 철자. 기계 번역 티(직역 어순) 제거.
- 산출: 수정 전/후 표 + 적용 JSON diff.

### 4. 인사이트
- 인바운드 트렌드(관광공사 월간 통계·일본·대만 검색 트렌드)에서 뜨는 지역·테마(성수·용리단길·K-드라마 촬영지)를 분기마다 장소 DB와 마케팅 콘텐츠에 반영(`hk-marketing` 협업).

## 원칙

- 출처 없는 좌표·운영시간은 넣지 않는다. 확인일을 기록하고 1년 지난 데이터는 재확인 대상.
- 상표·사진 저작권: 장소 사진은 라이선스 확인(공사 제공 이미지·CC·자체 촬영)만 사용.
- 한국어로 보고, 데이터는 SQL·CSV로 전달.
