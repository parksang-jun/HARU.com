# 규제·정책 체크리스트 (2026-10 조사 기준 — 분기마다 웹 검색으로 갱신)

## 출시 전 필수
- [ ] 개인정보 처리방침(4개국어): 수집 항목(익명 ID·여행 설정·대화 내용·대략 위치(선택)·광고 ID(배너 시)), 처리 목적, 보관 기간, 제3자·국외 이전(Supabase 리전, Anthropic 미국 — AI 입력 데이터 처리 고지), 삭제 방법, 운영자 정보, 개인정보 보호책임자
- [ ] 이용약관: 앱은 정보·링크 제공자이며 예약·결제·쿠폰 이행 당사자가 아님, AI 생성물의 한계·확인 의무, 면책, 준거법
- [ ] AI 생성 고지: 일정·챗 화면에 "AI 생성, 운영시간·가격 확인 필요"(한국 AI 기본법 2026-01-22 시행, 최소 1회 고지·1년 계도; EU AI Act Art.50 2026-12-02 유예 종료)
- [ ] 어필리에이트 고지: "예약 링크는 제휴 링크이며 추가 비용 없이 수수료를 받을 수 있음"(FTC 가이드·일본 ステマ 규제·한국 표시광고법)
- [ ] 스폰서 표시: 쿠폰 카드 "Sponsored/広告/廣告/광고" 라벨, 조건·기간 명시
- [ ] 여행업 등록: 직접 예약·결제·수탁이 없으면 통상 불필요 — 관광진흥법 기준으로 전문가 확인, 향후 자체 예약 도입 시 재검토
- [ ] 스토어: 개인정보 라벨, 위치 사용 설명(쿠폰 거리 계산, 선택), 외부 링크 결제 정책 설명(앱 내 구매 없음), 연령 등급
- [ ] 사업자 정보 표기(상호·대표·사업자번호·연락처) 앱 더보기·웹 푸터

- 일일 사용 한도·남용 차단(IP·다계정) 시 개인정보 최소 수집
