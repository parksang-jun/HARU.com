# Haru Korea 운영팀 (haru-korea-team)

한국 인바운드 여행자(일본·대만·영어권)를 위한 AI 여행 컨시어지 앱 **Haru Korea**(OTA 어필리에이트 + 로컬 쿠폰 스폰서 광고 수익)를 2027년에 출시하고 운영하기 위한 업무를 7명의 담당으로 나눈 플러그인입니다. 각 담당을 호출하면 그 업무의 전문가로서 일합니다.

## 팀 구성과 호출 방법

| 담당 | 호출 | 시키는 일 예시 |
|------|------|----------------|
| 운영총괄 PM | `/hk-pm` | "다음 뭐 해야 해?", "주간 점검", "수익 깔때기 상태" |
| 앱·백엔드 개발 | `/hk-dev` | "이 버그 고쳐줘", "Supabase 배포 절차", "주간 쿼리 뽑아줘" |
| AI 품질·비용 | `/hk-ai` | "이 일정 품질 평가해줘", "추론 비용 줄여줘", "프롬프트 수정" |
| 제휴·광고주 영업 | `/hk-partnerships` | "Klook 제휴 신청 소개문", "명동 매장 제안서", "광고주 월간 리포트" |
| 장소 데이터·로컬라이즈 | `/hk-content` | "제주 장소 60곳 추가", "일본어 문구 검수", "벚꽃 시즌 콘텐츠" |
| 광고·마케팅 | `/hk-marketing` | "인스타 릴스 캘린더(일본어)", "샤오홍슈 콘텐츠", "대만 Meta 광고 캠페인" |
| CS·신뢰·규제 | `/hk-cs` | "이 문의 답변 써줘", "AI 고지 문구 점검", "심사 거절 대응" |

슬래시 명령 대신 자연어로 말해도 됩니다 — "인스타 광고 만들어줘"라고 하면 광고·마케팅 담당이 나섭니다.

## 추천 워크플로우 (2027 출시 로드맵)

1. `/hk-pm` — 앱명·계정·Supabase 프로젝트 확정, 로드맵 단계 진단
2. `/hk-partnerships` — OTA 어필리에이트 가입(승인 전엔 Book 버튼 수익 0), 파일럿 광고주 10곳
3. `/hk-content` + `/hk-ai` — 장소 DB 검증·확장, 일정 품질 채점·프롬프트 v2, 세션당 비용 ≤ $0.05
4. `/hk-marketing` — 일본·대만 인플루언서 베타, 벚꽃 시즌 콘텐츠, 유료 광고 테스트
5. `/hk-dev` — 스토어·웹 릴리스, MCP 앱 디렉토리 제출, 주간 깔때기 쿼리
6. `/hk-cs` — 출시 후 문의·오류 신고·규제 점검 루틴

## 권장 세팅

- **주간 운영 점검 예약 작업**: 플러그인 설치 후 "매주 월요일 아침에 `/hk-pm` 주간 점검 리포트를 예약해줘"라고 요청하면 PM이 로드맵·지표·정책 변화를 점검해 이번 주 액션을 제안하는 Claude 예약 작업이 등록됩니다.

## 참고

- 제휴 조건·광고 단가·정책은 변동되므로 각 담당이 답변 전 웹 검색으로 최신 확인하도록 설계되어 있습니다.
- 개인정보·AI 고지·광고 표시·여행업 등록 등 법률 사안은 정보 제공용이며, 실행 전 전문가 확인을 권합니다.
