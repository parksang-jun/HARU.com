# 예약 작업 (하루 운영 에이전트를 실제로 돌리는 방법)

자동 실행은 **클라우드 예약 작업** 또는 **이 맥(launchd)** 중 한쪽만 쓴다. 둘 다 켜면 같은 일을 두 번 한다.
맥 운영센터는 화면 확인·결재·명령·수동 실행용이다.

| 이름 | 일정 (cron, Asia/Seoul) | 루틴 |
|---|---|---|
| 하루 주간 운영 점검 | 매주 월 09:13 (`13 9 * * 1`) | AGENT.md 루틴 A |
| 하루 제휴·광고주 | 매주 수 10:07 (`7 10 * * 3`) | AGENT.md 루틴 B |
| 하루 월간 정산 | 매월 3일 10:22 (`22 10 3 * *`) | AGENT.md 루틴 C |
| 하루 제품 개선 | 매주 화·금 10:41 (`41 10 * * 2,5`) | AGENT.md 루틴 D |
| 하루 마케팅 콘텐츠 | 매주 목 10:37 (`37 10 * * 4`) | AGENT.md 루틴 E |
| 하루 여행 데이터 점검 | 매주 토 09:27 (`27 9 * * 6`) | AGENT.md 루틴 F |
| 하루 명령 처리 | 매일 08~23시 매시간 (`0 8-23 * * *`) | AGENT.md 1-2 — 라벨 `command` 이슈(작성자 parksang-jun)만 처리. 없으면 즉시 종료 |

**현재 상태: 클라우드 예약은 아직 등록하지 않았다.** 사장님이 켜 달라고 하면 아래 틀로 등록한다.

## 공통 프롬프트 틀

```
당신은 여행 준비 앱 "하루(Haru)"의 운영 에이전트입니다. 사용자는 자리에 없으니 질문하지 말고 진행하세요. 답변과 리포트는 한국어로, 간결하게.
1) GitHub 저장소 parksang-jun/HARU.com 을 push 권한으로 세션에 추가해 받으세요(main 브랜치).
2) ops/agent/AGENT.md(헌장)와 ops/agent/state/ 를 읽고 권한표를 지키세요.
3) 헌장의 "루틴 <A|B|C|D|E|F>"를 수행하세요. 결과는 ops/agent/reports/ 에 쓰고 agent/ 브랜치에 커밋·푸시, PR 생성.
4) 리포트 파일을 사용자에게 보내고 마지막 메시지에 요약과 "승인 요청 목록"을 적으세요.
```

루틴별 추가 지시는 `mac/run-routine.sh` 의 `EXTRA` 와 같다.
