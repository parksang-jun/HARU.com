# 비용 원칙 — 돈이 나가지 않는 연결만 쓴다 (2026-11-26, 사장님 결정)

| 용도 | 쓰는 것 | 비용 | 상태 |
|---|---|---|---|
| 숙소 가격·평점 | 아고다 제휴 API | 무료(예약 시 수수료 수입) | 제휴 가입·키 필요 |
| 항공 운임 | Travelpayouts 제휴 API | 무료(수수료 수입) | 키 필요 |
| 액티비티 | Klook·KKday 제휴 링크 | 무료(수수료 수입) | 제휴 가입 필요. 평점 API 는 승인 후 확인 |
| 맛집·장소 평점 | **API 를 쓰지 않는다.** "평점·후기 보기" 버튼으로 구글 지도 검색을 연다 | 무료(링크) | 적용됨 |
| 지도·동선 | 좌표 계산으로 직접 그림 | 무료 | 적용됨 |
| 광고 | AdMob | 무료(수입) | 실제 광고 ID 필요 |

## 쓰지 않기로 한 것
- Google Places API (평점·후기): 무료 한도 뒤로 건당 과금. 넣지 않는다.
- 유료 지도 타일, 유료 환율·번역 API.

## 아직 돈이 드는 것 (결정 필요)
1. **AI 일정·상담** — 호출마다 과금. 지금은 서버 일일 한도(일정 5회, 질문 40개)와 보상형 광고로 묶어 두었다.
2. **날씨** — Open-Meteo 무료 서버는 비상업용. 광고·제휴 수익이 있는 앱은 유료 키가 필요하다.
3. **Supabase** — 무료 요금제 한도 안에서는 0원.
4. 스토어 등록비(애플 연 단위, 구글 1회)는 API 와 무관하게 든다.

## 규칙
새 외부 서비스를 붙일 때는 이 표에 먼저 올리고, "무료(제휴·링크)"가 아니면 사장님 승인 전에는 연결하지 않는다.
